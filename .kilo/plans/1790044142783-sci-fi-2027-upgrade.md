# Sci-Fi 2027 Portfolio Upgrade Plan

## Context
Upgrade existing portfolio (Kry Vichhika) to a sci-fi 2027 aesthetic. All content/information stays identical — only visual style, animations, and layout patterns change.

## Files to Modify
1. `src/index.css` — Global sci-fi theme variables, new keyframe animations, utility classes
2. `src/components/Hero.jsx` — Bigger title with animated lighting/glow sweep effect
3. `src/components/Skills.jsx` — Convert grid to horizontal auto-scroll with pause-on-hover
4. `src/components/Project.jsx` — Redesign project cards with new sci-fi layout
5. `src/App.jsx` — Update background gradient overlays for sci-fi palette
6. `index.html` — Update title

---

## Task 1: Global Sci-Fi Theme (`src/index.css`)

- Update CSS variables for more neon/cyber palette:
  - `--accent`: `#00f5e4` (cyan neon)
  - `--accent2`: `#a855f7` (purple neon)
  - `--glow`: brighter glow values
  - New `--neon-blue`: `#0066ff`
  - New `--neon-pink`: `#ff006e`
- Add new keyframe animations:
  - `@keyframes neon-pulse` — pulsing glow on text
  - `@keyframes light-sweep` — horizontal light sweep across text (for hero title)
  - `@keyframes glitch-flicker` — occasional glitch effect
  - `@keyframes scan-line` — horizontal scanning line animation
  - `@keyframes float-slow` — slow floating orb animation
- Add utility classes:
  - `.neon-text` — animated neon glow text
  - `.light-sweep` — lighting sweep animation on text
  - `.sci-fi-border` — animated border with gradient
  - `.holo-card` — holographic card effect
- Update grid background to finer, more futuristic pattern

## Task 2: Hero Title — Bigger + Lighting Animation (`src/components/Hero.jsx`)

- Increase name font size from `clamp(2.5rem, 7vw, 5rem)` to `clamp(3.5rem, 10vw, 7rem)`
- Add `light-sweep` class to the name `<h1>` element
- Add animated text-shadow that cycles through neon colors
- Add a subtle glitch effect that triggers every few seconds
- Keep all other hero content (buttons, photo, social links) unchanged

## Task 3: Skills Horizontal Auto-Scroll with Pause on Hover (`src/components/Skills.jsx`)

- Convert skills container from `grid` to horizontal scroll layout
- Add CSS animation `auto-scroll` that translates the container horizontally
- On hover over the skills container, set `animation-play-state: paused`
- Keep all skill information (name, level, desc, icon, cat) identical
- Each skill card keeps its content and progress bar
- Add a gradient fade mask on left/right edges to indicate scrolling

## Task 4: Project Display Redesign (`src/components/Project.jsx`)

- Redesign project cards with a new sci-fi "command terminal" layout:
  - Each project shown as a full-width "terminal window" with:
    - Top bar with window controls (red/yellow/green dots) + project codename
    - Left side: animated holographic preview area (image with scan-line overlay)
    - Right side: info panel with date, title, description, features, stack
  - Add staggered entrance animation for each project
  - Add holographic shimmer effect on hover
  - Features list displayed as glowing tag chips instead of checkmarks
  - Stack tags with animated border glow on hover
- Keep ALL project data (title, date, description, features, stack, URLs, images) identical

## Task 5: App Background Update (`src/App.jsx`)

- Update gradient overlay colors to match new neon palette
- Add a subtle animated background element (floating orbs or grid distortion)

## Task 6: Title Update (`index.html`)

- Change `<title>` to "Kry Vichhika — Sci-Fi 2027"
